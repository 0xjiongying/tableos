## Dual narrative (non-negotiable)

| Layer | Role |
|---|---|
| **Hospitality OS** | What guests and staff *feel* — technology disappears; service feels effortless |
| **Programmable money** | What operators and investors *see* when they look under the table — Value Streams on Arc |

Premium dining is the **beachhead setting**. Condition-gated settlement is the **company**. Marketing tells a day-in-service story while Value Streams make money tangible — never a POS brochure, never a crypto dashboard.

**Brand line:** *The operating system of hospitality.*  
**Settlement line:** Escrow → condition → atomic split → treasury (USDC on Arc).

---

## Experience philosophy

1. **Technology disappears** — Omotenashi first; chain chrome never.
2. **Hospitality is choreography** — reserve → hold → acknowledge → settle as continuous service flow.
3. **Money is alive** — Value Streams visualize authorize → escrow → settle → distribute → treasury.
4. **Everything has rhythm** — time-of-day ambience; hospitality motion primitives (arrival, acknowledgment, handoff, completion, waiting).
5. **Trust through transparency** — escrow/settlement states are observable without neon theatre.

---

## Signature metaphor: Value Streams (under hospitality)

Every payment is a **continuous stream**. Streams merge, split, lock, release, accumulate, and rebalance — expressed as architectural lines and liquid geometry, never glowing crypto particles.

The stream is always framed by service language on guest/staff surfaces (“Your seat is held,” “Door acknowledges”) and financial language where operators opt into treasury depth.

### Explicitly forbidden aesthetics

- Glowing blockchain particles  
- Hexagons / floating coins  
- Crypto neon gradients  
- Chatbot-first AI chrome  
- Generic restaurant POS layouts  
- Feature-card dumps without editorial chaptering

## Motion language by financial state

| State | Motion character | Implementation cue |
|---|---|---|
| Authorization | Firm commit | Stream arrives / locks intent |
| Escrow | Contained hold | Waiting / breath opacity |
| Confirmation | Acknowledgment | Soft scale / handoff |
| Settlement | Release | Path opens downstream |
| Distribution | Fork | Staggered parallel paths |
| Treasury | Pool | Basin fill / settle |
| Forecast | Quiet projection | Low-opacity write |

**Hospitality UI primitives** remain: arrival · acknowledgment · handoff · completion · waiting (`hospitalityMotion` + CSS tokens).

**Time-of-day:** `html[data-tod]` morning → afternoon → evening → night.

**`prefers-reduced-motion`:** zero durations; state clarity without animation.
